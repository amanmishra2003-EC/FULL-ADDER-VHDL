## Overview
A Full adder is a combinational circuit that adds two -bit binary input and a carry generated from previous bit addition.

## Logic equation
<br>
SUM = A XOR B
<br>
CARRY = A AND B

## Simulation
<br>
*inputs:* A,B,Cin
<br>
*Outputs:* SUM, CARRY
<br>
*Language:* VHDL
<br>
*Tools:* Modelsim
